## 2. Approach Analysis & Comparison

| Approach | Description | Time Complexity | Space Complexity | Pros / Cons |
|---|---|---|---|---|
| **Array stack** (`array-stack`) | Uses an indexed array as a LIFO stack. Pushes opening brackets, pops when matching closing bracket found. | $O(n)$ | $O(n)$ | Canonical CS solution. Linear time, optimal for arbitrarily nested brackets. |
| **Repeated pair removal** (`repeated-pair-removal`) | Filters non-bracket characters and repeatedly strips adjacent matching pairs `()`, `[]`, `{}` using `${s//...}` until string is empty. | $O(n^2)$ | $O(n)$ | Very concise, showcases Bash parameter expansion pattern substitution. Quadratic in worst-case nesting. |
